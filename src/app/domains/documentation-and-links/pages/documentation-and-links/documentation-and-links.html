What is NgRx?

NgRx is a state management library for Angular based on Redux principles. It provides predictable state transitions, easier debugging, and efficient data sharing through actions, reducers, effects, and selectors.

NgRx is built around four core concepts: Actions, Reducers, Selectors, and Effects

Actions

Actions describe what happened in the application and are used to update the state.

Reducers

Reducers update the state based on actions and return a new state.

Selectors

Selectors get specific data from the state so components don’t need the whole store.

Effects

Effects handle async tasks like API calls when actions are triggered and can dispatch new actions with the result.
